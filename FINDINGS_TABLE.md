| **SEC-01** | SQL Injection Authentication Bypass | A03:2021-Injection / A07:2021-Auth Failures | CWE-89 | **9.8 (Critical)** | `POST /rest/user/login`<br>`email` | Submitting `' OR 1=1--` with dummy password returns `200 OK` and admin JWT token (`admin@juice-sh.op`). | Raw string concatenation in Sequelize SQL query string without parameter binding. | Full administrative account takeover, total database compromise, GDPR violation. | Use parameterized queries with Sequelize ORM `where` clause or bind variables. |
| **SEC-02** | Weak Password Requirements & No Rate Limiting | A07:2021-Auth Failures | CWE-521 / CWE-307 | **7.5 (High)** | `POST /rest/user/login`<br>`POST /api/Users` | Allows single-character passwords; 100+ automated rapid login attempts succeed without throttling/lockout. | No schema-level complexity check; absence of rate-limiting middleware on auth routes. | High exposure to credential stuffing, dictionary brute-force, and account takeover. | Enforce 12+ character complex password policy (Zod/Joi) and integrate `express-rate-limit`. |
| **SEC-03** | Insecure Direct Object Reference (IDOR) on Basket | A01:2021-Broken Access Control | CWE-639 | **8.5 (High)** | `GET /rest/basket/{bid}`<br>`basketId` | Authenticated user (`bid=3`) alters path to `/rest/basket/2` and retrieves another user's cart contents and prices. | Server trusts client-controlled path parameter without verifying against JWT session user identity. | PII exposure, order tampering, unauthorized cart snooping, privacy law breach. | Bind object operations strictly to `req.user.bid` extracted from validated server JWT token. |
| **SEC-04** | Missing Function-Level Access Control (Admin Panel) | A01:2021-Broken Access Control | CWE-285 | **8.8 (High)** | `GET /#/administration`<br>`GET /api/Users/` | Non-admin user can access administrative interface directly and fetch all registered users and data. | Client router lacks route guards and backend API lacks role-based access control (RBAC) middleware. | Privilege escalation, user deletion/modification, systemic administrative compromise. | Implement server-side role validation middleware (`verifyRole('admin')`) and Angular `AdminGuard`. |
| **SEC-05** | DOM-Based Cross-Site Scripting (XSS) in Search | A03:2021-Injection | CWE-79 | **6.1 (Medium)** | `/#/search?q=`<br>`q` parameter | Submitting `<iframe src="javascript:alert('XSS')">` triggers script execution in the DOM without sanitization. | Search query is injected directly into DOM innerHTML using Angular `bypassSecurityTrustHtml`. | Session token hijacking (JWT in localStorage), phishing overlays, credential theft. | Remove security bypass, utilize standard Angular interpolation `{{ query }}`, sanitize with DOMPurify. |
| **SEC-06** | SQL Injection in Product Search Filtering | A03:2021-Injection | CWE-89 | **8.6 (High)** | `GET /rest/products/search?q=`<br>`q` | Injecting `q')) UNION SELECT id,email,password,'4','5','6','7','8','9' FROM Users--` leaks user credentials in product table. | Raw concatenation of user search parameter into SQL `LIKE` statement in product query. | Unauthorized database extraction, mass credential leakage, intellectual property theft. | Utilize parameterized queries with Sequelize `Op.like` pattern bindings. |
| **SEC-07** | Missing Defensive Security Headers & Info Leakage | A05:2021-Security Misconfiguration | CWE-1021 / CWE-693 | **6.5 (Medium)** | HTTP/1.1 Response Headers | Missing `Content-Security-Policy`, `X-Frame-Options`, `HSTS`; leaks `Server: Express` banner. | Express server runs with default unhardened HTTP headers and framework banner enabled. | Clickjacking via iframe framing, MIME-type sniffing attacks, targeted framework vulnerability probing. | Implement `helmet` middleware suite with strict CSP, `frameguard: { action: 'deny' }`, and `hidePoweredBy`. |
